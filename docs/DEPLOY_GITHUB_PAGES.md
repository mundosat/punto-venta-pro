# Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todo el contenido de este ZIP.
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
5. Guarda.
6. Espera a que GitHub genere la URL pública.

## Recomendación

Usa un repositorio como:

`punto-venta-pro`

y la URL quedará parecida a:

`https://tuusuario.github.io/punto-venta-pro/`

## CORS y dominios autorizados

En Firebase Authentication agrega tu dominio de GitHub Pages como dominio autorizado si es necesario.
